# Observation features (`ember-gen-v2`)

Generated by `ember features` from `src/encode.rs` (`feature_names()`); do not edit by hand.
The layout and its meaning were designed in the maintainers' internal notes (`GENERAL_ENV.md` §5, "G5 status" and "ember-gen-v2"), which are not part of this repository.

Select `ember-gen-v3` to compute individual and party levels from all declared classes. V2 and v3 have the same tensor shapes and use the base hero for both identity embeddings. A fresh v3 learner can import v2 weights with `--transfer-v2-weights` and `--init-heroes` or `--init-monsters`.

Dimensions: N = 24, T = 8, creature = 183, global = 34, cand = 122, map_channels = 17, canvas = 32, relations = 5.

`ember-gen-v1` (still available, `Version::V1`) is the prefix of each array: creature 0-159, global 0-31, candidate 0-111, map channels 0-15; no `creature_rel`.
